# 夸克接入

## 当前路线

直接扫码流程由 Android 实现：请求授权页、显示二维码、轮询确认、兑换会话、读取授权目录与下载地址。参考 quarkclouddrive CLI 1.0.18 的 Agent 授权协议；不在车机运行 Node.js 或 Python，不包含 CLI 自动更新、会话追踪或文件上传／删除功能。

参考项目：[quarkclouddrive](https://github.com/quark-clouddrive/quarkclouddrive_offical)。备用网页二维码与会话协议参考 [QuarkPan](https://github.com/lich0821/QuarkPan)。协议可能变化；实验流程成功不等于平台为本项目分配了独立应用身份。

## 本地客户端配置

复制 `android-app/config/quark_cli_client.example.json` 到 `android-app/app/src/main/assets/quark_cli_client.json`，填写适用于该使用场景的 `clientId` 和 `signKey`。真实文件不纳入 Git，仓库不会代替构建者取得客户端配置。

缺少或留空配置时，应用仍可构建；直接授权会提示安装包未配置。不要把用户授权码、访问令牌、刷新令牌或 Cookie 填进该客户端配置。

客户端签名参数进入 APK 后可被提取，不能视为设备端不可读取的秘密。部署需要后端保管的长期应用密钥时，应采用独立获准的服务端方案，不能将本实验协议适配视为同一资质。

## 会话保存与目录访问

用户令牌通过 Android Keystore 加密保存；切换或重新选择来源时复用账号。访问令牌失效或临近到期时刷新，同账号并发请求合并；访问和刷新令牌一致保存，旧响应不能覆盖新会话。

授权页面验证 HTTPS、预期主机和路径，以及页面码绑定；兑换时核对设备绑定。二维码可刷新，授权码输入只作为备用。只访问用户实际授权的目录；手机页面上的长期授权截止日期不是访问令牌寿命。

目录按服务端游标翻页，检测循环并保留完整 FID；下载地址临时解析。读取所需请求头仅发送至对应来源，日志不输出带凭证的地址或令牌。

## 验证与限制

已有隔离验证版完成新授权、目录扫描、首次播放、主动刷新、刷新后直接网络 Range 读取和进程恢复。到期后的并发刷新与旧响应保护由本机测试覆盖；未等待长期授权自然到期，也未完成所有实车验收。详见 [测试说明](../android-app/TESTING.md)。

`open-service/` 是早期专用连接服务原型，目前没有对应的应用配置入口，不属于当前直接扫码所需部署组件。它保留为研发参考，准入、回调和刷新路由必须独立验证。
