# Cruise Tune 支持的功能

Cruise Tune 是面向定制 Android 车机的本地音乐播放器。功能按“本地可用”“需要用户配置”和“需要目标车机验证”区分；完整的播放约束见 [架构说明](architecture.md)，界面行为见 [设计说明](design.md)。

## 曲库与播放

- 扫描本地音乐目录，建立持久化曲库；支持递归扫描、分页读取和来源去重。
- 通过默认夸克网页扫码登录或可选 Token 配置读取授权网盘目录。
- 按歌曲名称、目录或文件名对曲库和队列排序，并保留当前歌曲和进度。
- 支持上一首、下一首、播放／暂停、进度调整、顺序、随机和循环播放。
- 使用 Android Media3 播放服务、媒体会话和音频焦点，支持车机后台播放。
- 保存播放位置、队列和播放意图；启动后恢复队列，默认等待用户继续。
- 可在设置中开启开机后的播放器入口通知；默认关闭。点按通知打开应用并恢复队列，是否继续播放由独立的播放开关控制。

## 缓存与离线

- 优先读取完整离线文件，其次读取可淘汰的流式缓存，最后从网盘分段读取。
- 默认按真实播放顺序预缓存后 3 首完整歌曲，不按网络类型限制。
- 当前歌曲可以主动保留离线，界面区分等待、下载中、已保留、失败和可重试状态。
- 对明确的文件错误或完整缓存停滞执行一次旁路重读；恢复成功后再重建缓存。
- 夸克网页登录连续两次确认云端歌曲已失效时，保留队列顺序并标记该歌曲，自动跳到下一首；完整缓存仍可播放。
- 网络、登录、权限和无进度等待不会直接当作坏歌跳过；确认文件错误后才按队列规则处理。
- 熄屏、用户暂停、切歌和音频焦点变化会取消不适用的恢复或预缓存任务。

## 歌词、封面与界面

- 显示当前歌曲的封面、歌手和专辑信息。
- 优先读取内嵌歌词，也支持同目录同名 `.lrc`；带时间戳歌词同步显示，纯文本歌词可手动滚动。
- 封面与歌词绑定实际播放曲目，切歌时不把旧曲目的内容带到新曲目。
- 支持横竖屏布局、日／夜模式、对比度、减少透明效果和减少动态效果。
- 支持手动底部留白；窗口、弹窗遮罩和触摸范围会同时避让原车 Dock 区域。

## 车机适配

- 可选 OneOS 方向盘按键适配，默认关闭。
- OneOS 适配检查系统服务身份、Binder 接口、监听注册和当前媒体菜单。
- 支持播放、上一首、下一首的单击映射，以及双击、长按和检测模式配置。
- 标准 Android 媒体键继续由 Media3 处理；OneOS 事件和标准事件会按时间窗口去重。
- 可选原车仪表媒体同步，入口为「设置 → 车辆 → 仪表媒体显示」。
- 仪表同步会检查目标接收器的 action、组件、导出属性、系统应用身份和权限。
- 仪表同步发送歌曲、歌手、播放状态、时长和位置；发送成功只代表系统接受广播，不代表仪表已经显示。
- 熄屏、暂停、播放错误、切歌恢复和关闭同步时会清理已经发布的播放状态。

## 诊断与数据保护

- 方向盘和仪表功能均提供脱敏诊断信息，便于复制服务状态、接收器状态、UID、重试和最近错误。
- 诊断信息不包含账号、令牌、Cookie、VIN、Android ID、文件路径或完整系统日志。
- 用户凭证使用 Android Keystore 加密保存；网盘客户端配置不作为仓库密钥使用。
- 应用不依赖 Google Play 服务，也不要求把用户账号或真实曲库打包进测试数据。

## 当前边界

- 当前正式来源是本地目录和夸克；阿里云盘、百度网盘等没有作为已接入来源发布。
- OneOS 按键、原车仪表接收器、Ecarx VHAL 和车机音频焦点行为必须在目标固件上确认；普通模拟器只能验证应用逻辑。
- 仪表封面同步尚未开放，待文字、状态、位置和实车接收行为确认后再增加。
- 播放核心不依赖 QQ 音乐或其它第三方播放器的专用 AIDL。
