本版改进播放异常恢复，并扩大横屏主播放按钮的可用宽度。

### 更新内容

- “重试当前歌曲”真正重新加载当前项，保留队列和播放位置，不再只重复发送无效的准备指令。
- 随机／顺序切换改为移动已有队列项，保留当前播放的解码和缓冲状态。
- 文件解析产生的 EOF 不再按网络中断持续重试；正常弱网读取仍保留重试。
- 疑似损坏的流式缓存自动绕过重读一次；实际播放恢复后，下载完整新副本并重建该歌曲的流式缓存，不自动删除已保留的离线音乐。
- 自动重读仍失败或超时则跳过当前歌曲；整轮队列均失败时停止，避免列表循环中反复跳歌。网络、登录和权限错误不按坏歌连续跳过。
- 暂停、切歌和熄屏会取消未完成的恢复。横屏上一首、播放／暂停、下一首按钮铺满左侧播放面板，保留原有触控高度与按压反馈。

### 验证范围

补充缓存恢复、循环边界、取消及连续播放进度检查。本版未进行模拟器或实车音频输出回归；缓存修复不等于整文件哈希校验，也不代表所有车机播放停滞原因均已解决。
