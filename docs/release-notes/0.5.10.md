本版汇总自 0.5.3 以来的登录、曲库、缓存与界面修复。

### 更新内容

- 夸克默认使用网页扫码登录，复用已保存会话；Token 授权继续作为可选方式。网页登录使用经实测的 PC 文件取址方式，支持按需读取音乐。
- 登录失效时保留原队列与播放位置，提供重新连接入口；明确区分网络缓冲、授权失效和文件大小限制。
- 已登记的账号与目录直接复用曲库；跨登录方式首次确认关联后不重复扫描。支持清理本机旧来源与 Token 授权，网盘文件保留。
- 修复首次播放已读完文件、末片却尚未提交导致缓存状态迟迟不完整的问题；存在真实缺口时仍显示部分缓存。
- 小屏保留播放状态并支持查看完整详情，优化窄竖屏和大字体布局；循环模式改为直接单选并展示当前值。
- 来源移除收进管理页，确认框增大文字并区分危险操作；缓存状态在后台查询，播放进度独立刷新。

### 验证与说明

本地 123 项 Android 自动化测试和 Release Lint 通过；BlueStacks 已验证保留数据更新、横竖屏与大字体布局、模式选择、播放、自动切歌和进度拖动。模拟器结果不替代实车验收，也不代表声音卡顿已全面解决。

当前 Token 下载接口曾实测返回 50 MiB 单文件限制；本版没有解除该接口限制。网页与 Token 的跨方式关联需要首次确认同一账号、同一目录，不会仅凭目录名称自动合并。
