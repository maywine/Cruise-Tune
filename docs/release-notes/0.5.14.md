本版新增当前歌曲大封面、离线保留入口和双行同步歌词，并改善小屏与大字体下的播放操作。

### 更新内容

- 居中显示歌曲封面、歌手和专辑信息；封面保持静止，切歌轻微淡入淡出，并尊重系统减少动态效果设置。
- 支持本地或已授权网盘目录中的同名 `.lrc` 文件，显示当前句与下一句，随播放和进度拖动同步；可手动切换回封面。
- 当前歌曲可保留离线，明确区分等待下载、下载中、已保留、暂停和重试；普通播放缓存不会被误标为“已保留”。
- 小窗口可在页面内展开封面与歌词，歌名、进度及上一首／播放或暂停／下一首保持可操作，返回后恢复列表位置。
- 修复切换封面／歌词时重复读取、拖动预览被播放时间覆盖，以及歌手／专辑信息加载导致封面尺寸变化的问题。
- 空音乐库按钮改为“添加音乐”，并适配小屏大字体。

歌词文件需与音频位于同一目录且名称对应，例如 `Song.flac` 与 `Song.lrc`；暂不读取 FLAC 内嵌歌词。
