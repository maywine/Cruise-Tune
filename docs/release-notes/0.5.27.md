新增可选 OneOS 方向盘按键适配，入口为「设置 → 方向盘按键」。0.5.26 未完成发布，其功能随本版提供。

- 播放键、左右键支持单击、双击和长按映射；默认单击对应播放／暂停、上一首、下一首，双击和长按不执行。
- 核验输入服务和系统 SDK 后注册监听；接收及执行前读取媒体菜单，切换菜单、未知状态或查询失败时取消动作。
- 支持按键去重、350ms 双击识别、长按松手保护、断连重连，以及“只检测按键，不控制播放”模式。
- 动作复用现有播放服务，保留暂停、熄屏、音频焦点与完整缓存播放保护。
- 修正缓存选择测试中的模拟音频时钟，避免短音频提前播完造成不稳定断言；没有更改应用的播放、缓存或按键逻辑。

车机专用适配默认关闭，标准媒体按键仍可使用。真实 OneOS 权限、服务编号、菜单值及原厂 QQ 音乐是否同时响应，仍需领克 01 实车验证。
