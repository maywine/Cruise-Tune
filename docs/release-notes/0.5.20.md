修复 0.5.19 缓存恢复流程中的网络重试与误跳歌问题。

- 绕过疑似损坏缓存重读时，网络超时、断连和可重试服务错误继续退避重试；等待期间保留当前歌曲、队列和播放位置。
- 取消“恢复超过 45 秒就跳歌”的判断。慢网和网络连通状态不作为文件损坏的证据，只有明确的文件错误才进入失败跳过流程。
- 离线时发现疑似缓存问题，也会建立恢复读取，由网络重试等待恢复连接。
- 播放器直接上报临时网络错误时，恢复流程保留旁路状态并安排重新加载；暂停、切歌、熄屏仍能取消待执行的重试。
- 登录失效、权限错误与未知错误不按坏歌自动跳过。

209 项 Android 主机测试和 Release Lint 通过。验证使用真实 Media3 解析器、播放器与合成数据，覆盖损坏缓存后连续网络失败再恢复、长时间等待、保留曲目和位置，以及取消行为。BlueStacks 已验证保留数据覆盖更新、启动与正常播放；模拟器未人为破坏真实缓存，实车音频效果仍需另行验收。
