### 更新内容

- Media3 统一升级至 1.11.0，包含音频输出短暂不足时的缓冲状态防抖，以及解码器接收输入前 flush 的兼容修复。
- 已完整缓存的歌曲约 10 秒没有实际播放进展时，可触发一次旁路重读；缓冲／播放状态反复切换不会刷新计时。
- 初次停滞超时错误也可进入恢复，不再只等待文件解析报错；暂停、切歌与熄屏仍可取消恢复。
- 重读中的网络错误继续退避重试，保留当前歌曲、位置和播放意图。不因无进度或网络等待超时跳歌，只有明确文件错误才按失败预算跳过。

### 验证范围

本机回归覆盖 API 28（Android 9）与 API 33 的状态切换、网络重试、长时间等待和取消边界。尚未完成本版实车音频输出验收，不能仅凭类似症状认定为 Android 9 系统或特定厂商驱动的问题。
